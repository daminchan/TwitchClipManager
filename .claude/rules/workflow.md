# 実装ワークフロー

## 実装前（必須）

- **MUST**: 不明点があれば質問してから着手
- **MUST**: 実装前にタスク名・変更ファイル・方針を宣言し確認を取る
- **NEVER**: 確認なしで実装を開始しない

## 実装中

- **MUST**: 命名規則に従う（`code-style.md`参照）
- **MUST**: Props型を定義
- **MUST**: 定数は`lib/constants.ts`から取得
- **MUST**: 50行超えのコンポーネントは分割
- **SHOULD**: 各ファイル変更後に進捗を報告

## 実装後

- **MUST**: 不要なコード・コンソールログを削除
- **MUST**: 重複コードがないか確認
- **MUST**: `npm run build` でビルド確認、エラーがあれば修正
- **MUST**: コミット前に変更ファイルとメッセージ案を提示
- **NEVER**: ユーザー承認なしでコミット・プッシュしない
