### 4. hooks/use-dashboard-clips.ts

**変更**: 手動 fetch → React Query の `useQuery` / `useMutation`

**主な変更点**:

#### Before（手動管理）
```typescript

const fetchAllFavoriteClips = async () => {
  const response = await fetch(url, { cache: 'no-store' });
  setAllClips(data);
};
```

#### After（React Query）
```typescript
const { data: allClips = [], isLoading } = useQuery({
  queryKey: ['clips', 'favorites', clipFilter],
```

**説明**:
- ✅ `cache: 'no-store'` 削除（React Query が管理）
- ✅ クリップ取得: `useQuery` でキャッシュ付き取得

- ✅ キャッシュ無効化: `invalidateQueries` でお気に入り変更時のみ再取得
- ✅ 手動の `useState` / `useEffect` を削除

## 🔑 React Query の核心機能

### 1. 自動キャッシュ

```typescript
useQuery({
  queryKey: ['clips', 'favorites', 'WEEK'],
  queryFn: fetchClips,
  staleTime: 5 * 60 * 1000, // 5分間はキャッシュを使用
})
```

**仕組み**:
- 初回: API呼び出し → メモリにキャッシュ
- 5分以内: キャッシュから即座に返す
- 5分以上: バックグラウンドで再取得

### 2. キャッシュ無効化

```typescript
// お気に入り追加時
queryClient.invalidateQueries({ queryKey: ['clips'] });
// → 'clips' を含むキャッシュを「古い」とマークして再取得
```

**仕組み**:
- お気に入り変更 → キャッシュを無効化
- 次回アクセス時 → 必ず最新データを取得

### 3. 楽観的更新（Optimistic UI）

```typescript
useMutation({
  mutationFn: addLikedClip,
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['clips', 'liked'] });
  },
})
```

**仕組み**:
- いいねクリック → 即座にUIを更新
- バックグラウンドで API 呼び出し
- 成功したらキャッシュを更新

## 📊 キャッシュ戦略

### キャッシュキーの設計

| キャッシュキー | 用途 | 無効化タイミング |
|---------------|------|----------------|
| `['clips', 'favorites', filter]` | お気に入り配信者のクリップ | お気に入り追加/削除時 |
| `['clips', 'liked']` | いいねしたクリップ | いいね追加/削除時 |

**設計理由**:
- フィルターごとにキャッシュを分離
- お気に入り変更時のみ該当キャッシュを無効化

## 🎯 効果測定

### Before（現状）
```
【ユーザー操作】                  【API呼び出し】
1. ダッシュボード表示              → 5回（お気に入り5人分）
2. フィルター変更「7日→3日」        → 5回（再取得）
3. ソート変更「再生数→新しい順」    → 5回（再取得）
4. タブ切り替え「設定→ホーム」      → 5回（再取得）
5. お気に入り追加（6人目）         → 6回（全員分再取得）

合計: 26回のAPI呼び出し
読み込み時間: 2秒 × 5回 = 10秒
```

### After（React Query 導入後）
```
【ユーザー操作】                  【API呼び出し】
1. ダッシュボード表示              → 5回（初回のみ）
2. フィルター変更「7日→3日」        → 5回（キャッシュなし）
3. ソート変更「再生数→新しい順」    → 0回（キャッシュから即座）
4. タブ切り替え「設定→ホーム」      → 0回（キャッシュから即座）
5. お気に入り追加（6人目）         → 6回（キャッシュ無効化）

合計: 16回のAPI呼び出し（約40%削減）
読み込み時間: 2秒 × 2回 = 4秒（60%短縮）
```

**5分以内の再アクセスの場合**:
```
合計: 6回のAPI呼び出し（約77%削減）
読み込み時間: 0秒（即座に表示）
```

## 🔍 デバッグ方法

### React Query DevTools の使用

```
開発環境（npm run dev）で自動的に表示される画面右下のアイコン:
┌─────────────┐
│  React Query │  ← クリックで展開
│    DevTools  │
└─────────────┘

確認できる情報:
- 現在のキャッシュ状態
- queryKey ごとのデータ
- stale（古い）/fresh（新しい）の状態
- 最終更新時刻
- refetch（再取得）の実行
```

### よくある問題と解決策

| 問題 | 原因 | 解決策 |
|-----|------|--------|
| キャッシュが更新されない | `invalidateQueries` 未実行 | `queryClient.invalidateQueries()` 追加 |
| 無限ループ | `useEffect` の依存配列に queryKey | React Query に任せて `useEffect` 削除 |
| データが古い | `staleTime` が長すぎる | `staleTime` を短くする |
